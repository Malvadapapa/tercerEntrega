## 📌 Descripción

Esta tercera entrega del trayecto formativo en **NUCBA** profundiza en la creación de interfaces web completas mediante una arquitectura de archivos modular. Integra componentes independientes de navegación (`nav.html`, `nav.css`), galerías de productos/servicios y elementos dinámicos mediante JavaScript.

---

## ✨ Características

- 🧱 **Arquitectura de Estilos Modular:** Desacoplamiento de reglas CSS entre el layout global (`style.css`) y componentes de navegación (`nav.css`).
- 📱 **Diseño Adaptativo (Responsive Design):** Flexibilidad ante pantallas de smartphones, portátiles y monitores de escritorio.
- ⚡ **Interactividad Frontend:** Script `main.js` para manipulación de eventos y dinamismo en la navegación.
- 🎨 **Secciones Semánticas:** Estructura clara con cabecera, contenido central, secciones destacadas y footer.

---

## 🗂️ Estructura del Proyecto

```bash
tercerEntrega/
│
├── index.html       # Página principal y punto de integración
├── nav.html         # Componente modular de navegación
├── main.js          # Controladores de interactividad
├── style.css        # Estilos generales del proyecto
├── nav.css          # Estilos dedicados de la barra de navegación
├── assets/          # Imágenes y recursos multimedia
└── README.md        # Documentación técnica
```
